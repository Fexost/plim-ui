A full-width sheet anchored to the bottom of the viewport. Escape and backdrop click emit closed so the parent can set open to false.

Open and close

Project any content. The overlay is created only while open.

Share this page with a link or export.

 
<button type="button" plimButton (click)="open.set(true)">Open sheet</button>

<plim-bottom-sheet [open]="open()" ariaLabel="Share options" (closed)="open.set(false)">
  <p>Share this page with a link or export.</p>
  <button type="button" plimButton (click)="open.set(false)">Done</button>
</plim-bottom-sheet>

Accessibility

✓

Accessibility guidance

The sheet is presented as a modal dialog. Provide an ariaLabel when the content has no visible heading.

  • Modal dialog semantics
  • Escape and backdrop dismiss
  • Focus trapped while open

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
open boolean false When true, attaches a bottom CDK overlay. No overlay when false.
ariaLabel string — Accessible name forwarded to the sheet.

Outputs

Output Type Description
closed void Emitted on Escape or backdrop click. Set open to false.
