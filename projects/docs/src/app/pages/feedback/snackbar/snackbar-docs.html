A non-blocking message at the bottom of the viewport. It auto-closes after duration unless that value is 0.

Variants

Match badge semantics with variant: default, primary, success, warning, or danger.

@if (variant() === 'success') { Changes saved } @else if (variant() === 'warning') { Storage almost full } @else if (variant() === 'danger') { Could not delete item } @else if (variant() === 'primary') { Updates available } @else { Message sent } 
<plim-snackbar
  [open]="open()"
  variant="success"
  [duration]="0"
  (closed)="open.set(false)"
>
  Changes saved
</plim-snackbar>

Accessibility

✓

Accessibility guidance

The snackbar is a live region. It does not use a blocking backdrop so the rest of the page stays usable.

  • Status live region with configurable politeness
  • Optional dismiss action
  • No focus trap or blocking overlay
  • Do not rely on colour alone — keep the message text explicit

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
open boolean false When true, attaches a bottom-centre overlay. No overlay when false.
variant 'default' | 'primary' | 'success' | 'warning' | 'danger' 'default' Semantic tint matching plim-badge variants.
duration number 4000 Auto-close delay in milliseconds. 0 stays open.
ariaLive 'polite' | 'assertive' | 'off' 'polite' Live region politeness.

Outputs

Output Type Description
closed void Emitted after duration or when Dismiss is clicked. Set open to false.
