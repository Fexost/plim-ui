A modal dialog centred over the page. Escape and backdrop click emit closed so the parent can set open to false.

Open and close

Project a title, body, and actions. The overlay is created only while open.

Delete item

This action cannot be undone. The item will be removed permanently.

 
<button type="button" plimButton (click)="open.set(true)">Open dialog</button>

<plim-dialog [open]="open()" ariaLabel="Delete item" (closed)="open.set(false)">
  <h2 plimDialogTitle>Delete item</h2>
  <p>This action cannot be undone.</p>
  <div plimDialogActions>
    <button type="button" plimButton variant="text" (click)="open.set(false)">
      Cancel
    </button>
    <button type="button" plimButton (click)="open.set(false)">Delete</button>
  </div>
</plim-dialog>

Accessibility

Accessibility guidance

The dialog uses role="dialog" with a focus trap. The first focusable control is focused on open and focus is restored when the overlay closes.

  • Modal dialog semantics
  • Escape and backdrop dismiss
  • Focus first control, restore on close

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
open boolean false When true, attaches a centred CDK overlay. No overlay when false.
ariaLabel string — Accessible name forwarded to the dialog.

Outputs

Output Type Description
closed void Emitted on Escape or backdrop click. Set open to false.

Content slots

Attribute Description
plimDialogTitle Heading at the top of the dialog.
default Dialog body content.
plimDialogActions Action row at the bottom of the dialog.
