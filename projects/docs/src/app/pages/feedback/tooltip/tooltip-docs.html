A short hint shown on hover or focus. Apply plimTooltip to the trigger element; set plimTooltipPosition to prefer above or below.

Below (default)

The tooltip opens below the trigger when space allows.

<button
  type="button"
  plimButton
  variant="secondary"
  plimTooltip="Copied to clipboard"
>
  Copy
</button>

Above

Set plimTooltipPosition="above" to prefer opening above the trigger.

<button
  type="button"
  plimButton
  plimTooltip="Save changes"
  plimTooltipPosition="above"
>
  Save
</button>

Accessibility

✓

Accessibility guidance

The overlay uses role="tooltip" and is linked to the host with aria-describedby while visible. Show on pointer enter and focus; hide on leave and blur.

  • Tooltip role on the overlay panel
  • Described-by relationship while open
  • Keyboard focus and pointer both reveal the message

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
plimTooltip string '' Tooltip message. An empty string keeps the overlay closed.
plimTooltipPosition 'above' | 'below' 'below' Preferred placement. Falls back to the opposite side when needed.
