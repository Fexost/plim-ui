A searchable command menu rendered in a CDK overlay. Filter items as the user types, navigate results with arrow keys, and select with Enter. The parent controls open, supplies items, and handles selected / closed.

Open and filter

Provide labelled items with optional descriptions. Set --plim-command-palette-offset on a parent to position the panel below a sticky header. 

<button type="button" plimButton (click)="open.set(true)">
  Open command palette
</button>

<plim-command-palette
  [open]="open()"
  [items]="items()"
  [query]="query()"
  placeholder="Search commands…"
  ariaLabel="Example command palette"
  (queryChange)="query.set($event)"
  (selected)="onSelected($event)"
  (closed)="onClosed()"
/>

Accessibility

Accessibility guidance

The palette uses a combobox pattern: the query field has role="combobox" with aria-expanded, aria-controls, and aria-activedescendant while results are listed. Escape and backdrop click emit closed and focus returns to the trigger.

  • Arrow keys cycle through results
  • Enter selects the active result
  • Focus trap while open; restore focus on close
  • Body scroll locked while the overlay is open

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
open boolean false When true, attaches a centred CDK overlay below the header offset.
items CommandPaletteItem[] [] Results to render. Each item needs id and label.
query string '' Current filter text shown in the search field.
placeholder string 'Search…' Placeholder for the query input.
ariaLabel string 'Command palette' Accessible name for the combobox.
emptyMessage string 'No results found.' Shown when items is empty.

Outputs

Output Type Description
queryChange string Emitted when the user edits the filter text.
selected CommandPaletteItem Emitted when the user activates a result (Enter or click).
closed void Emitted on Escape or backdrop click. Set open to false.

CommandPaletteItem

Property Type Description
id string Stable identifier passed to selected.
label string Primary result text.
description string Optional secondary line (for example a category).
