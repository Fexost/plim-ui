Accessibility

PLIM treats accessibility as a baseline requirement. Components use semantic HTML first, keyboard support by default, and ARIA only when native semantics are not enough.

01

Semantic structure

Use the correct HTML elements for landmarks, headings, buttons, and links.

02

Keyboard and focus

All interactive components must be operable by keyboard with visible focus.

03

ARIA with restraint

Add ARIA only when it improves assistive technology behaviour.
