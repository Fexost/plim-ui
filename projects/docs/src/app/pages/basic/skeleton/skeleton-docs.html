Placeholder shapes for loading states. Use while content is fetching instead of empty space or layout shift. Decorative only — mark surrounding regions with aria-busy when appropriate.

Accessibility

Accessibility guidance

Skeleton hosts use aria-hidden="true". Pair with a visible loading label or set aria-busy="true" on the parent region until content loads.
