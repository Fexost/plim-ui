A styled native button for actions. Apply plimButton to keep semantic behaviour, keyboard support, and visible focus.

Variants

Choose a visual weight that matches the action priority.

<button type="button" plimButton>Primary</button>
<button type="button" plimButton variant="secondary">Secondary</button>
<button type="button" plimButton variant="text">Text</button>
<button type="button" plimButton disabled>Disabled</button>

States

Hover, focus (Tab), and press the preview buttons to see interaction feedback. Disabled and loading states are shown below.

Default

Use for the primary action on a surface.

Secondary

Use for supporting actions beside a primary button.

Disabled

Use when the action is unavailable. Binds to the native disabled attribute.

Loading

Set loading during async work. The button is disabled and exposes aria-busy.

Accessibility

Accessibility guidance

Buttons use native semantics so assistive technology gets role, state, and keyboard behaviour without extra ARIA.

  • Enter and Space activate
  • Focus ring stays visible
  • Native disabled state

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
variant 'primary' | 'secondary' | 'text' 'primary' Visual style of the button.
disabled boolean false Disables the native button.
loading boolean false Shows a spinner, disables the button, and sets aria-busy.
