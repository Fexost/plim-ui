A segmented control for choosing one or many options. Wrap toggles in plim-button-toggle-group and bind the selected value or values.

Single selection

Only one toggle stays selected at a time.

<plim-button-toggle-group [(value)]="view">
  <button type="button" plimButtonToggle="list">List</button>
  <button type="button" plimButtonToggle="grid">Grid</button>
  <button type="button" plimButtonToggle="table">Table</button>
</plim-button-toggle-group>

Multiple selection

Add multiple to allow more than one active toggle.

<plim-button-toggle-group multiple [(values)]="ingredients">
  <button type="button" plimButtonToggle="flour">Flour</button>
  <button type="button" plimButtonToggle="eggs">Eggs</button>
  <button type="button" plimButtonToggle="sugar">Sugar</button>
</plim-button-toggle-group>

Accessibility

✓

Accessibility guidance

Each toggle is a native button with aria-pressed reflecting selection state.

  • Group uses role="group"
  • aria-pressed on each toggle
  • Native button keyboard support

CSS variables this component reads from the design system.

API reference

Button toggle group

Input Type Default Description
multiple boolean false Allows more than one selected toggle.
value string '' Selected value in single-select mode. Supports two-way binding.
values string[] [] Selected values in multiple mode. Supports two-way binding.

Button toggle

Input Type Default Description
plimButtonToggle string — Value reported to the group when selected.
disabled boolean false Disables the toggle.
