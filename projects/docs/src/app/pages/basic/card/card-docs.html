A bordered surface for grouping related content. Project a header, body, and footer with the card slots.

Layout

Combine optional header and footer slots around the default body content.

Title

Body content

 
<plim-card>
  <div plimCardHeader>Title</div>
  <p>Body content</p>
  <div plimCardFooter>
    <button type="button" plimButton>Action</button>
  </div>
</plim-card>

Accessibility

✓

Accessibility guidance

Cards are presentational containers. Use headings inside the card when the grouped content needs a document outline.

  • Use semantic headings in the body when appropriate
  • Keep actions in the footer as native buttons or links

API reference

Input Type Default Description
fill boolean false Stretches the card to the height of its container and pins the footer to the bottom.

Content slots

Attribute Description
plimCardHeader Title or summary row at the top of the card.
plimCardFooter Actions or metadata at the bottom of the card.
default Main card body content.
