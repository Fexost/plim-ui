Indicates that content is loading. Name the spinner with aria-label when it appears without accompanying text.

Sizes

Match the spinner to the control or section it accompanies.

<plim-spinner size="sm" aria-label="Loading" />
<plim-spinner size="md" aria-label="Loading" />
<plim-spinner size="lg" aria-label="Loading" />

Accessibility

✓

Accessibility guidance

The host uses role="status" and an accessible name so screen readers announce loading state.

  • Status role on the host
  • Configurable aria-label
  • Respects reduced-motion preferences

API reference

Input Type Default Description
size 'sm' | 'md' | 'lg' 'md' Spinner dimensions.
aria-label string 'Loading' Accessible name for the loading indicator.
