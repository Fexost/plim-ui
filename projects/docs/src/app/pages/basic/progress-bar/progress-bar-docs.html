Shows task completion for determinate work, or ongoing activity when progress is unknown. Name the bar with aria-label when no visible label is present.

Modes

Set a percentage for determinate progress, or switch to indeterminate for loading.

<plim-progress-bar [value]="60" aria-label="Upload progress" />

<plim-progress-bar mode="indeterminate" aria-label="Loading content" />

Accessibility

Accessibility guidance

The host uses role="progressbar". Determinate bars expose aria-valuenow; indeterminate bars omit it.

  • Progressbar role on the host
  • Configurable aria-label
  • Respects reduced-motion preferences

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
value number 0 Completion percentage for determinate mode (0–100).
mode 'determinate' | 'indeterminate' 'determinate' Determinate shows fill amount; indeterminate animates activity.
aria-label string 'Progress' Accessible name for the progress bar.
