Accessibility

Accessibility guidance

When src is set, the image uses the provided alt text. Initials fall back to decorative presentation when adjacent text names the person.

  • Image alt text supported
  • Initials marked aria-hidden when used decoratively

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
size 'sm' | 'md' | 'lg' 'md' Avatar dimensions.
src string — Optional image URL.
alt string '' Alternative text for the image.
