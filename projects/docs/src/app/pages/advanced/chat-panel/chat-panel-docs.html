Floating widget

plim-chat-widget renders a fixed launcher and CDK overlay panel. Project the same plim-chat-panel markup shown above, bind [(open)] to control visibility, and use [fixed]="false" when the launcher should sit inside a container instead of the viewport.

Use the Ask button in the bottom-right corner of this page to try the live widget. Escape or Close dismisses the panel. 

<plim-chat-widget
  [(open)]="open"
  [fixed]="false"
  ariaLabel="Documentation assistant"
  launcherLabel="Ask"
  (closed)="open.set(false)"
>
  <plim-chat-panel aria-label="Documentation assistant">
    ...
  </plim-chat-panel>
</plim-chat-widget>

Accessibility

Accessibility guidance

Name the panel with aria-label when the header does not expose a visible title. The messages region uses role="log" with a polite live region for incoming replies.

  • Named panel landmark
  • Polite live region for messages
  • Widget panel uses role="dialog" with focus trap
  • Launcher exposes aria-expanded and toggles the panel closed when clicked again
  • Escape closes the floating widget
  • Starter prompts are native buttons with visible focus
  • Send button disabled until there is a draft
  • Messages region scrolls to the latest turn automatically

Design tokens

CSS variables this component reads from the design system.

API reference

Panel inputs

Input Type Default Description
ariaLabel string — Accessible name for the panel when the header lacks a visible title.
messagesLabel string 'Messages' Accessible name for the scrollable messages region.

Widget inputs

Input / output Type Default Description
open Model<boolean> false Whether the overlay panel is visible.
fixed boolean true Pin the launcher to the viewport. Set false to position within a container.
showLauncher boolean true Render the built-in launcher trigger.
launcherLabel string 'Chat' Label for the built-in launcher.
launcherAriaLabel string — Optional accessible name when the visible label is not enough.
ariaLabel string — Accessible name for the overlay panel.
closed Output<void> — Emits when the widget requests close (Escape).

Content slots

Attribute Description
plimChatPanelHeader Title row, actions such as close or open full page.
plimChatPanelMessages Scrollable conversation history, intro copy, prompts, and turns.
plimChatPanelComposer Question input — typically plim-chat-composer.
plimChatPanelFooter Optional supporting note below the composer.

Conversation elements

Project these elements inside plimChatPanelMessages for empty states and turns.

Element Notes
plim-chat-intro Short heading above starter prompts or an empty state.
plim-chat-prompt-set Vertical stack wrapper for suggested prompts. Optional aria-label.
plim-chat-prompt Pill button for a suggested prompt. Emits selected when clicked.
plim-chat-message Conversation turn. Set role="user" for a right-aligned bubble or role="assistant" for plain assistant text.

Composer

plim-chat-composer wraps a single-line input and Send action in one rounded row. Enter or Send submits and clears the field.

Input / output Type Default Description
label string 'Your question' Visible label for the input. Omit with an empty string for a placeholder-only prompt.
placeholder string '' Placeholder text.
sendLabel string 'Send' Label for the submit button.
value Model<string> '' Two-way model for the draft message.
submitted Output<string> — Emits trimmed text when Send is clicked or Enter is pressed. Clears the field after emit.
