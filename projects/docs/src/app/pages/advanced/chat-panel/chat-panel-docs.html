Accessibility

Accessibility guidance

Name the panel with aria-label when the header does not expose a visible title. The messages region uses role="log" with a polite live region for incoming replies.

  • Named panel landmark
  • Polite live region for messages
  • Starter prompts are native buttons with visible focus
  • Send button disabled until there is a draft
  • Enter or Send submits
  • Messages region scrolls to the latest turn automatically

Design tokens

CSS variables this component reads from the design system.

API reference

Inputs

Input Type Default Description
ariaLabel string — Accessible name for the panel when the header lacks a visible title.
messagesLabel string 'Messages' Accessible name for the scrollable messages region.

Content slots

Attribute Description
plimChatPanelHeader Title row, actions such as close or open full page.
plimChatPanelMessages Scrollable conversation history, intro copy, or starter prompts.
plimChatPanelComposer Question input — typically plim-chat-composer.
plimChatPanelFooter Optional supporting note below the composer.

Message utilities

Style projected content inside plimChatPanelMessages with these classes.

Class Description
plim-chat-panel__intro Short heading above starter prompts or an empty state.
plim-chat-panel__prompts Vertical stack wrapper for suggested prompt buttons.
plim-chat-panel__prompt Pill button for a suggested prompt. Wire (click) to submit or prefill.
plim-chat-panel__message--user User turn — right-aligned bubble on a raised surface.
plim-chat-panel__message--assistant Assistant turn — plain text without a bubble.

Composer

plim-chat-composer wraps a single-line input and Send action in one rounded row. Enter or Send submits and clears the field.

Input / output Type Default Description
label string 'Your question' Visible label for the input. Omit with an empty string for a placeholder-only prompt.
placeholder string '' Placeholder text.
sendLabel string 'Send' Label for the submit button.
value string '' Two-way model for the draft message.
submitted Output<string> — Emits trimmed text when Send is clicked or Enter is pressed. Clears the field after emit.
