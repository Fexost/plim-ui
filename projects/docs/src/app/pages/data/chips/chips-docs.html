Compact tokens for a selected value, filter, or category. Wrap chips in plim-chip-set and project the label.

Set and removable

Use removable to show a dismiss control. The parent removes the chip.

@for (chip of chips(); track chip) { {{ chip }} } Disabled 
<plim-chip-set>
  <plim-chip removable (removed)="removeChip(chip)">Angular</plim-chip>
  <plim-chip disabled>Disabled</plim-chip>
</plim-chip-set>

Accessibility

✓

Accessibility guidance

Removable chips include a native dismiss button labelled Remove. Disabled chips expose aria-disabled.

  • Dismiss control is type="button"
  • Visible focus ring on the remove control
  • Disabled state forwarded to the dismiss button

API reference

Chip set

plim-chip-set is a wrapping flex container. It has no inputs.

Chip

Input Type Default Description
removable boolean false Shows a dismiss control that emits removed.
disabled boolean false Dims the chip and disables dismiss.
Output Type Description
removed void Emitted when the dismiss control is activated.
