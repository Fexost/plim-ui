A post-it style surface for short notes, reminders, or a public sticky-note wall. Supports colour variants and optional removal.

Variants

Use variant for colour treatments and removable for dismissible notes.

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore. Ut enim ad minim veniam, quis nostrud exercitation. 
<plim-sticky-note>
  Lorem ipsum dolor sit amet, consectetur adipiscing elit.
</plim-sticky-note>

<plim-sticky-note variant="primary">
  Sed do eiusmod tempor incididunt ut labore.
</plim-sticky-note>

<plim-sticky-note variant="warning" removable>
  Ut enim ad minim veniam, quis nostrud exercitation.
</plim-sticky-note>

Accessibility

Accessibility guidance

  • Remove control exposes an accessible name via removeLabel
  • Keep note copy concise and readable

Design tokens

API reference

Input / output Type Default Description
variant 'default' | 'primary' | 'warning' | 'success' 'default' Surface colour treatment.
removable boolean false Show a remove button.
removeLabel string 'Remove note' Accessible name for the remove button when removable is set.
removed Output<void> — Emits when the remove button is clicked.
