A stacked collection of items with list semantics. Mark an item disabled when it is not available.

Items

Project each row into plim-list-item.

Lorem ipsum dolor sit amet Consectetur adipiscing elit Sed do eiusmod tempor 
<plim-list>
  <plim-list-item>Lorem ipsum dolor sit amet</plim-list-item>
  <plim-list-item>Consectetur adipiscing elit</plim-list-item>
  <plim-list-item disabled>Sed do eiusmod tempor</plim-list-item>
</plim-list>

Interactive items

Add interactive for selectable rows. Use selected to mark the current choice.

Notifications Appearance Privacy Unavailable 
<plim-list-item interactive>Notifications</plim-list-item>
<plim-list-item interactive selected>Appearance</plim-list-item>
<plim-list-item interactive>Privacy</plim-list-item>

Density

Set density="compact" on plim-list for tighter rows.

Notifications Appearance Privacy 
<plim-list density="compact">
  <plim-list-item>...</plim-list-item>
</plim-list>

Loading and empty states

Use skeleton placeholders while fetching and a single status row when there are no items.

@if (loading()) { } @else if (empty()) { No items yet. } @else { Lorem ipsum dolor sit amet Consectetur adipiscing elit }

Accessibility

Accessibility guidance

The list uses role="list" and each item uses role="listitem". Disabled items set aria-disabled.

  • List and listitem roles on the hosts
  • Disabled state exposed to assistive technology

Design tokens

CSS variables this component reads from the design system.

API reference

List

Input Type Default Description
density 'comfortable' | 'compact' 'comfortable' Row padding preset.

List item

Input Type Default Description
disabled boolean false Marks the item unavailable and applies muted styling.
interactive boolean false Enables hover, focus, and pressed feedback for selectable rows.
selected boolean false Highlights the current item and sets aria-selected.
