A stacked collection of items with list semantics. Mark an item disabled when it is not available.

Items

Project each row into plim-list-item.

Lorem ipsum dolor sit amet Consectetur adipiscing elit Sed do eiusmod tempor 
<plim-list>
  <plim-list-item>Lorem ipsum dolor sit amet</plim-list-item>
  <plim-list-item>Consectetur adipiscing elit</plim-list-item>
  <plim-list-item disabled>Sed do eiusmod tempor</plim-list-item>
</plim-list>

Accessibility

Accessibility guidance

The list uses role="list" and each item uses role="listitem". Disabled items set aria-disabled.

  • List and listitem roles on the hosts
  • Disabled state exposed to assistive technology

List
