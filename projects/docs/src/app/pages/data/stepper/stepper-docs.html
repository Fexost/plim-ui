A linear sequence of steps. The stepper renders a header, the selected step body, and Back / Next controls. Bind selectedIndex when the parent needs the current step.

Linear steps

Mark a step optional to show a hint in the header.

Enter a name and email for the account. Add an optional display name. Confirm the details before finishing. 
<plim-stepper>
  <plim-step label="Account">Enter a name and email for the account.</plim-step>
  <plim-step label="Profile" optional>Add an optional display name.</plim-step>
  <plim-step label="Review">Confirm the details before finishing.</plim-step>
</plim-stepper>

Accessibility

Accessibility guidance

The header is a labelled progress navigation. The active step uses aria-current="step". Unselected step bodies are hidden.

  • Header labelled as progress
  • Current step announced with aria-current
  • Back and Next are native buttons

API reference

Stepper

Input Type Default Description

Step

Input Type Default Description
