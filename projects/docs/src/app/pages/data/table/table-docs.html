Styles a native table. Apply plimTable and keep semantic thead / tbody markup. Column headers align with cell content (left-aligned, with row dividers).

Basic table

Use native rows and cells. Pair with sort headers when columns should be sortable.

Name Role
Ada Engineer
Grace Architect 
<table plimTable>
  <thead>
    <tr>
      <th>Name</th>
      <th>Role</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>Ada</td><td>Engineer</td></tr>
    <tr><td>Grace</td><td>Architect</td></tr>
  </tbody>
</table>

Accessibility

Accessibility guidance

The host remains a native table, so column headers and row relationships stay intact.

  • Use th for column headers
  • Keep header and body groups
  • Add plimSort when columns should announce sort state

Design tokens

CSS variables this component reads from the design system.

API reference

table[plimTable] is an attribute component. It has no inputs.
