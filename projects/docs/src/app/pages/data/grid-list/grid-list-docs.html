A CSS grid of tiles. Set cols on plim-grid-list and project content into each plim-grid-tile.

Columns

Defaults to two columns. This preview uses three.

Accessibility

Accessibility guidance

The grid is a layout container. Use headings or landmarks inside tiles when the content needs a document outline.

  • Tiles are presentational surfaces
  • Keep interactive content as native controls inside each tile

Design tokens

CSS variables this component reads from the design system.

API reference

Grid list

Input Type Default Description
cols number 2 Number of equal-width columns.

Grid tile

plim-grid-tile projects its content. It has no inputs.
