A nested hierarchy of nodes. Nest plim-tree-node elements and toggle parents that have children.

Nested nodes

Parents expand and collapse. Leaves render as static labels.

<plim-tree>
  <plim-tree-node label="src">
    <plim-tree-node label="app">
      <plim-tree-node label="app.ts" />
    </plim-tree-node>
  </plim-tree-node>
  <plim-tree-node label="README.md" />
</plim-tree>

Accessibility

✓

Accessibility guidance

The tree uses role="tree" and each node uses role="treeitem". Parents expose aria-expanded.

  • Tree and treeitem roles
  • Expand toggle is a native button
  • Child group is hidden while collapsed

API reference

Tree

plim-tree has no inputs.

Tree node

Input Type Default Description
label string — Required node label.
expanded boolean false Whether child nodes are visible. Supports two-way binding.
