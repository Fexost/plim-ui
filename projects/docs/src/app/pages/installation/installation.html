Add plim-ui to an Angular app, import the components you need, and load the global stylesheet once. Design tokens and theming are covered in Foundations.

Install the package

npm install plim-ui

Requires Angular 21+ and these peer dependencies:

  • @angular/cdk — overlay components (dialog, menu, select, command palette)
  • @angular/common, @angular/core, @angular/forms
  • @angular/platform-browser

Include styles

@use 'plim-ui/styles/styles';

Add this once in your application styles (for example styles.scss). In angular.json, point the app styles array at your entry file after building or linking the library.

Global styles apply design tokens, a thin page scrollbar, and utilities such as .plim-kbd. See Theme for light and dark mode (data-theme="light" on the document root).

Icons (optional)

Components do not bundle an icon font. Load Material Symbols once if you use icons in your app shell — see the Icons guide.

Import components

import {{ '{' }} Button, Card, CommandPalette, Option, Select {{ '}' }} from 'plim-ui';

All components are standalone — add them to the imports array of your component or route. Form controls that implement ControlValueAccessor work with reactive and template-driven forms.

App shell

For a docs-style layout with header, sidebar, and command-palette search, follow the App shell guide. This documentation site is the reference implementation.

Contribute locally

The source lives on GitHub. Clone the repo and run the docs app: 

git clone https://github.com/Fexost/plim-ui.git
cd plim-ui
npm install
npm start
