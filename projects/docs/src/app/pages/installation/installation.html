Get started

Installation

Install plim-ui from npm, import standalone components into your Angular app, and include the global styles to enable design tokens and theming.

Install the package

npm install plim-ui

Requires Angular 21+.

Import components

import {{ '{' }} Header, Button, Sidebar {{ '}' }} from 'plim-ui';

All components are standalone — add them to the imports array of your component or route.

Include styles

@use 'plim-ui/styles/styles';

Add this once in your application styles (for example styles.scss) to load design tokens and theme variables.

Contribute locally

The source lives on GitHub. Clone the repo and run the docs app: 

git clone https://github.com/Fexost/plim-ui.git
cd plim-ui
npm install
npm start
