Add plim-ui to an Angular app, import the components you need, and load the global stylesheet once. Design tokens and theming are covered in Foundations.

Install the package

npm install plim-ui

Requires Angular 21+.

Import components

import {{ '{' }} Badge, Button, Card, Header, Sidebar {{ '}' }} from 'plim-ui';

All components are standalone — add them to the imports array of your component or route.

Include styles

@use 'plim-ui/styles/styles';

Add this once in your application styles (for example styles.scss). See Theme for light and dark mode setup.

Contribute locally

The source lives on GitHub. Clone the repo and run the docs app: 

git clone https://github.com/Fexost/plim-ui.git
cd plim-ui
npm install
npm start
