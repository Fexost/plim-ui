Installation

PLIM is developed as a local Angular library in this workspace. Build the library, import components, and include the global styles in your app.

Build the library

npm run build

Import components

import {{ '{' }} Header, Button {{ '}' }} from 'plim-ui';

Include styles

@use 'plim-ui/styles/styles';

After building, global tokens and theme variables are available from dist/plim-ui/styles/styles.scss.

Run the docs app

npm start
