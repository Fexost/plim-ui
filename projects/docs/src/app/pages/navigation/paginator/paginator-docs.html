Page controls for long lists. Bind length, pageIndex, and pageSize, then update them from the page event. Choose <plim-select> or a native <select> for page size with pageSizeControl.

Plim page-size select

Default — pageSizeControl="plim" uses <plim-select> with <plim-option>. 

<plim-paginator
  [length]="100"
  [pageIndex]="pageIndex"
  [pageSize]="pageSize"
  pageSizeControl="plim"
  (page)="onPage($event)"
/>

Native page-size select

Set pageSizeControl="native" for a styled native <select>.

<plim-paginator
  [length]="100"
  [pageIndex]="pageIndex"
  [pageSize]="pageSize"
  pageSizeControl="native"
  (page)="onPage($event)"
/>

Accessibility

Accessibility guidance

The host is a navigation landmark. Previous and next are native buttons, disabled at the ends. The range text updates with aria-live="polite".

  • role="navigation" on the host
  • Named previous and next buttons
  • Live region for the current range
  • Labelled page-size control in both plim and native modes

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
length number 0 Total number of items.
pageSize number 10 Items shown on the current page.
pageIndex number 0 Zero-based page index.
pageSizeOptions number[] [5, 10, 25] Values offered in the page-size select. Empty hides the select.
pageSizeControl 'plim' | 'native' 'plim' <plim-select> with <plim-option>, or native <select>.
ariaLabel string 'Pagination' Accessible name for the navigation landmark.

Outputs

Output Type Description
page PageEvent Emits {{ '{' }} pageIndex, pageSize, length {{ '}' }} when the page or page size changes.
