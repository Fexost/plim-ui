A dropdown of actions attached to a trigger. Bind a plim-menu instance with [plimMenuTrigger]; items are native buttons.

Actions

Open the menu from a button. Escape and outside click close it.

<button type="button" plimButton [plimMenuTrigger]="menu">Actions</button>
<plim-menu #menu>
  <button type="button" plimMenuItem>Edit</button>
  <button type="button" plimMenuItem disabled>Archive</button>
</plim-menu>

Accessibility

Accessibility guidance

The trigger exposes aria-haspopup="menu" and expanded state. The panel uses role="menu"; items are native buttons with role="menuitem". Focus returns to the trigger on close.

  • Menu trigger semantics
  • Escape and outside click dismiss
  • Focus restore to the trigger
  • Disabled items stay in the list but cannot activate

API reference

Menu trigger

Input Type Default Description

Menu item

Input Type Default Description
