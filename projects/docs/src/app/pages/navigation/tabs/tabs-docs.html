Accessibility guidance

Tab buttons sit in a tablist with roving tabindex. Panels use role="tabpanel" and stay hidden unless selected.

  • tablist, tab, and tabpanel roles
  • Arrow Left/Right, Home, and End
  • Disabled tabs are skipped by the keyboard

API reference

Tab group

Input Type Default Description
selectedIndex number 0 Active tab index. Supports two-way binding.

Tab

Input Type Default Description
label string — Text shown on the tab button. Required.
disabled boolean false Prevents selection from click or keyboard.
