Styles native range inputs for selecting a value from a continuous range. Apply plimSlider and use native min, max, and step attributes.

States

Default, disabled, and invalid states.

<input type="range" plimSlider min="0" max="100" value="40" />
<input type="range" plimSlider min="0" max="100" disabled />
<input type="range" plimSlider min="0" max="100" invalid />

Accessibility

Accessibility guidance

Range inputs remain native elements. Pair with a visible label or aria-label when the purpose is not clear from context.

  • Native slider semantics
  • Keyboard arrow key support
  • Visible focus ring

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
invalid boolean false Applies invalid styling and sets aria-invalid.
