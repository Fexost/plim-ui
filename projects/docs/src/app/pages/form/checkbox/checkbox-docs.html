Accessibility

Accessibility guidance

Checkbox role and state come from the native input.

  • Wrap input and label text in <label>
  • Space toggles when focused
  • Use invalid for validation styling

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the checkbox.
