Accessibility

Accessibility guidance

The control uses role="switch" and keeps checkbox form semantics for reactive forms.

  • Label describes what toggles on or off
  • aria-checked reflects state
  • Space toggles when focused

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the switch.
