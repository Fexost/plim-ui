Accessibility

✓

Accessibility guidance

Group related radios with a shared name and a <fieldset>.

  • Arrow keys move within the group
  • Legend names the group
  • Each option has a visible label

API reference

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the radio button.
