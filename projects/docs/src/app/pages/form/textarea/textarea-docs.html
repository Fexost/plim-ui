Default, disabled, and invalid states.

Accessibility

Accessibility guidance

Native textarea semantics are preserved. Resize is vertical only by default.

  • Label every textarea
  • Use rows for a sensible default height
  • Describe errors with aria-describedby

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the textarea.
