Accessibility

Accessibility guidance

The input uses role="combobox" with an associated role="listbox" panel. Arrow keys, Enter, Home, End, and Escape are supported while the panel is open.

  • Pair with a visible label or plim-form-field
  • Provide ariaLabel or ariaLabelledBy when no visible label is present
  • Use invalid for validation styling and aria-invalid

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
placeholder string 'Search…' Placeholder shown when the input is empty.
maxSuggestions number 8 How many options to show on open and after filtering.
ariaLabel string — Accessible name when no visible label is associated.
ariaLabelledBy string — References the id of the element that labels the autocomplete.
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Disables the input and suggestion panel.

Option

Project options with plim-option. Same component as select.

Input Type Default Description
