Styles native text inputs with shared field tokens. Apply plimInput to keep semantic behaviour and Angular forms compatibility.

States

Default, disabled, and invalid states.

<input type="text" plimInput placeholder="Enter text" />
<input type="text" plimInput disabled placeholder="Disabled" />
<input type="text" plimInput invalid placeholder="Invalid" />

Accessibility

✓

Accessibility guidance

Inputs remain native elements, so labels, autocomplete, and validation work without extra ARIA when paired correctly.

  • Pair with a visible <label> or plim-form-field
  • Use invalid with aria-describedby for error text
  • Native disabled and readonly states

API reference

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the input.
