Composable field wrapper for labels, controls, hints, and error messages. Keeps layout concerns separate from individual controls.

Preview

Helper text Error message 
<plim-form-field>
  <label plimFormFieldLabel for="field">Label</label>
  <input id="field" type="text" plimInput placeholder="Enter text" />
  <span plimFormFieldHint>Helper text</span>
</plim-form-field>

<plim-form-field invalid>
  <label plimFormFieldLabel for="field-error">Label</label>
  <input id="field-error" type="text" plimInput invalid />
  <span plimFormFieldError>Error message</span>
</plim-form-field>

Accessibility

✓

Accessibility guidance

Associate labels with controls using for and id. Link errors with aria-describedby on the control.

  • One label per control
  • Hints stay visible; errors show when invalid is set
  • Does not replace native validation semantics

CSS variables this component reads from the design system.

API reference

Input Type Default Description
invalid boolean false Reveals the error slot styling and visibility.

Content slots

Attribute Description
plimFormFieldLabel Field label.
plimFormFieldHint Helper text below the control.
plimFormFieldError Error message; shown when invalid is true.
default The form control(s).
