Accessibility

✓

Accessibility guidance

Native selects expose platform picker behaviour and full keyboard support. Use a custom combobox only when native options are insufficient.

  • Label the select element
  • Group related options with <optgroup>
  • Mark placeholder options as disabled

API reference

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the select.
