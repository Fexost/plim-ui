Native HTML

Use plimSelect on a native <select> for matching field styling with standard <option> children. Add required only when you also want muted placeholder styling via CSS. 

<label for="select-native-demo">Choose an option</label>
<select id="select-native-demo" plimSelect required>

</select>

Accessibility

Accessibility guidance

The trigger uses role="combobox" with an associated role="listbox" panel. Arrow keys, Enter, Space, Home, End, and Escape are supported while the panel is open.

  • Pair with a visible label or plim-form-field
  • Provide ariaLabel or ariaLabelledBy when no visible label is present
  • Use invalid for validation styling and aria-invalid

CSS variables this component reads from the design system.

API reference

Input Type Default Description
placeholder string '' Fallback label when no option is selected.
ariaLabel string — Accessible name when no visible label is associated.
ariaLabelledBy string — References the id of the element that labels the select.
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Disables the select trigger and panel.

Native select

Apply plimSelect to a native <select> for field styling.

Input Type Default Description
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Native attribute. Disables the select.

Option

Project options with plim-option. Same component as autocomplete.

Input Type Default Description
value string '' Option value emitted by the select.
