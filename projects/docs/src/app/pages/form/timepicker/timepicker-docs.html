Custom time picker with scrollable hour and minute columns. Built with Angular CDK overlay. Use the native variant below when browser time inputs are enough.

States

Default, disabled, and invalid states.

<plim-timepicker placeholder="Select time" />
<plim-timepicker disabled placeholder="Select time" />
<plim-timepicker invalid placeholder="Select time" />

Native HTML

Apply plimTimepicker to a native <input type="time"> for matching field styling with browser-provided clock UI. 

<input type="time" plimTimepicker />
<input type="time" plimTimepicker disabled />
<input type="time" plimTimepicker invalid />

Accessibility

✓

Accessibility guidance

The custom timepicker exposes expanded/collapsed state and supports keyboard selection in the hour and minute columns. Pair with a visible label or plim-form-field.

  • Arrow keys move between options while the panel is open
  • Enter confirms the focused hour or minute
  • Use minuteStep to control minute increments
  • Native inputs keep standard time semantics and browser UI

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
placeholder string 'Select time' Fallback label when no time is selected.
minuteStep number 1 Minute increment in the custom picker columns. Typed values still accept any minute from 00–59.
ariaLabel string — Accessible name when no visible label is associated.
ariaLabelledBy string — References the id of the element that labels the timepicker.
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Disables the trigger and time panel.
