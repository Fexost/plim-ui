Styles native time inputs with shared field tokens. Apply plimTimepicker to keep semantic behaviour and Angular forms compatibility.

States

Default, disabled, and invalid states.

<input type="time" plimTimepicker />
<input type="time" plimTimepicker disabled />
<input type="time" plimTimepicker invalid />

Accessibility

✓

Accessibility guidance

Time inputs remain native elements. Pair with a label and use min/max/step when the allowed range matters.

  • Native time picker semantics
  • Browser-provided clock UI
  • Visible focus ring
