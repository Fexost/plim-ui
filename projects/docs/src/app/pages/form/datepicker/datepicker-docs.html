Custom calendar date picker with a themed overlay panel. Built with Angular CDK overlay and keyboard-friendly day selection. Use the native variant below when browser date inputs are enough.

States

Default, disabled, and invalid states.

<plim-datepicker placeholder="Select date" />
<plim-datepicker disabled placeholder="Select date" />
<plim-datepicker invalid placeholder="Select date" />

Native HTML

Apply plimDatepicker to a native <input type="date"> for matching field styling with browser-provided calendar UI. 

<input type="date" plimDatepicker />
<input type="date" plimDatepicker disabled />
<input type="date" plimDatepicker invalid />

Accessibility

Accessibility guidance

The custom datepicker trigger exposes expanded/collapsed state and associates the calendar grid with keyboard navigation. Pair with a visible label or plim-form-field.

  • Arrow keys move between days while the panel is open
  • Enter selects the focused day; Escape closes the panel
  • Use min and max to constrain selectable dates
  • Native inputs keep standard date semantics and browser UI

Design tokens

CSS variables this component reads from the design system.

API reference

Input Type Default Description
placeholder string 'Select date' Fallback label when no date is selected.
min string | null null Earliest selectable ISO date (YYYY-MM-DD).
max string | null null Latest selectable ISO date (YYYY-MM-DD).
ariaLabel string — Accessible name when no visible label is associated.
ariaLabelledBy string — References the id of the element that labels the datepicker.
invalid boolean false Applies error styling and aria-invalid.
disabled boolean false Disables the trigger and calendar panel.
