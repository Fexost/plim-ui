Accessibility guidance

The header renders a semantic landmark. Keep interactive content in slots limited to native links and buttons.

  • Semantic header landmark
  • Native controls in slots
  • External links use rel="noopener noreferrer"

API reference

Input Type Default Description
sticky boolean false Keeps the header visible at the top of the scroll container.

Content slots

Attribute Description
plimHeaderStart Leading content such as brand or menu toggle.
plimHeaderCenter Centred navigation or page title.
plimHeaderEnd Trailing actions such as theme toggle or external links.
