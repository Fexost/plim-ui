Use Google Material Symbols for icons. Load the font once, then render icons with a material-symbols-outlined element and the ligature name as text content.

Setup

Add the Material Symbols stylesheet to your app shell (already included in these docs): 

<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,400,0,0"
/>

Usage

Prefer outlined symbols. Pair decorative icons with visible text, or add an accessible name when the icon is the only label.

menu dark_mode check_circle 
<span class="material-symbols-outlined" aria-hidden="true">menu</span>

<button type="button" plimButton variant="secondary" aria-label="Switch theme">
  <span class="material-symbols-outlined" aria-hidden="true">dark_mode</span>
</button>

Colour

Use semantic icon colour tokens so icons match text hierarchy and status. Apply .plim-icon with size modifiers, or set font-size and color directly on Material Symbols.

search star check_circle warning error
Token Use
--plim-color-icon Default inline icons
--plim-color-icon-muted De-emphasized icons
--plim-color-icon-primary Brand or active icons
--plim-color-icon-success Success status icons
--plim-color-icon-warning Warning status icons
--plim-color-icon-danger Error status icons

Sizing

Prefer --plim-icon-size-* tokens so icons align with adjacent text and controls. Set font-size on the symbol element (Material Symbols are an icon font). Align icons inside buttons and navigation rows with flexbox.

Token Value Use
--plim-icon-size-sm 1rem Inline with body text, field adornments
--plim-icon-size-md 1.25rem Buttons and compact controls
--plim-icon-size-lg 1.5rem Section headings and prominent icons
--plim-icon-size-xl 1.75rem Section headings, empty states, large spinners
