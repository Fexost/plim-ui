Design tokens are CSS custom properties in the --plim-* namespace. They are organised in three layers — primitive (raw palette), semantic (purpose aliases such as --plim-color-surface), and component (dimensions and control-specific values). Use semantic and component tokens in your own styles instead of hard-coded values.

Token layers

Primitives (--plim-primitive-*) are defined in _primitives.scss and are not intended for direct use in components. Semantic tokens map primitives to roles and respond to data-theme. Component tokens capture shared dimensions (for example --plim-button-height).
