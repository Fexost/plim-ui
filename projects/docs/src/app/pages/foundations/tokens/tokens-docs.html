Design tokens are CSS custom properties in the --plim-* namespace. Use them in your own styles instead of hard-coded values so surfaces stay consistent with the library and respond to theme changes.

Colours

Token Usage
--plim-color-background Page background
--plim-color-surface Default surface (header, panels)
--plim-color-surface-raised Elevated surface (cards, previews)
--plim-color-border Default border
--plim-color-text Primary text
--plim-color-text-muted Secondary text
--plim-color-text-subtle Tertiary text, labels
--plim-color-primary Primary accent, links, focus
--plim-color-success Success states
--plim-color-warning Warning states
--plim-color-danger Error and destructive states
--plim-color-primary-surface* Tinted primary surfaces (notes, info callouts)
--plim-color-success-surface* Tinted success surfaces (positive callouts)
--plim-color-warning-surface* Tinted warning surfaces
--plim-color-danger-surface* Tinted danger surfaces

Spacing

A rem-based scale from --plim-space-1 (0.25rem) through --plim-space-12 (3rem).

Token Value
--plim-space-1 0.25rem
--plim-space-2 0.5rem
--plim-space-3 0.75rem
--plim-space-4 1rem
--plim-space-6 1.5rem
--plim-space-8 2rem
