plim-ui defaults to dark mode. Light mode overrides are applied when data-theme="light" is set on the document root. Colour tokens in Tokens update automatically.

Default (dark)

Dark values are defined on :root. No attribute is required — import the stylesheet and components render in dark mode. 

@use 'plim-ui/styles/styles';

Light mode

Set the attribute on <html> or <body> to swap surface, text, and shadow tokens. 

<html data-theme="light">
  ...
</html>

Toggle at runtime

Read the user preference, persist the choice, and update the attribute when the selection changes. 

document.documentElement.dataset.theme = 'light';
// or remove the attribute / set to 'dark'

The docs app uses a ThemeService that respects prefers-color-scheme on first visit and stores the choice in localStorage.

Color scheme hint

color-scheme is set alongside theme variables so native form controls and scrollbars match the active palette.
