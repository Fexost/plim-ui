Plim Design is the philosophy. plim-ui is the Angular library that implements it. This page points at the canonical sources. It does not restate them.

Philosophy

Plim Design is framework-agnostic. It is about intentional interfaces: purpose, hierarchy, states, accessibility, and identity that belongs to the product. It does not define a universal look, and plim-ui's theme is not that look.

Skills

The skills are how agents apply the philosophy. Install them from the Plim Design repository. The evals/ directory tests those skills. It is not design guidance. 

npx skills add Fexost/plim-design
  • plim-design — the reasoning to load first
  • plim-review — diagnosis without editing
  • plim-beautify — improve an existing interface
  • plim-accessibility — inclusion, including WCAG 2.2 AA
  • plim-responsive — adaptation across context
  • plim-ui — express those decisions with this library
