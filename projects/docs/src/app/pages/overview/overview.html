Angular component system

Interfaces that welcome everyone.

PLIM is an accessibility-first UI library for Angular — composable primitives, semantic tokens, and interaction patterns that work for keyboard, pointer, and assistive technology users.

Start in minutes

Angular 21+ 
npm install ui

Build the library locally, then import components and styles into your app.

✓

Accessibility is the baseline

Every component is built with semantic HTML, keyboard support, and visible focus states. ARIA is used only when native semantics are not enough.
