Interfaces that welcome everyone.

plim-ui is an accessibility-first UI library for Angular — composable primitives, semantic tokens, and interaction patterns that work for keyboard, pointer, and assistive technology users.

Start in minutes

Angular 21+ 
npm install plim-ui

Install from npm, import standalone components, and add the global stylesheet.

check_circle

Accessibility is the baseline

Semantic HTML, keyboard support, and visible focus are built in from the start.
